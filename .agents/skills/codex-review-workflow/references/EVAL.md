# Codex 운영 평가 기준 (운영본)

이 문서는 초안이 아니라 실제 병합 판단에 사용하는 운영 기준이다.

## 판정 체계

- 최종 판정은 `MERGE: PASS` 또는 `MERGE: HOLD`만 사용한다.
- 판정은 아래 `필수 게이트`를 먼저 확인한 뒤 결정한다.
- `필수 게이트` 하나라도 실패하면 무조건 `MERGE: HOLD`다.

## 필수 게이트 (Pass/Fail)

| Gate ID | 항목 | Pass 조건 | Fail 조건 |
| --- | --- | --- | --- |
| G1 | 도메인/비즈니스 무결성 | 핵심 사용자 흐름 회귀 없음 | 흐름 단절, 잘못된 분기, 요구사항 위반 |
| G2 | API/타입 안정성 | 타입 에러/계약 불일치 없음 | nullable/optional 누락, 계약 위반 |
| G3 | 인증/보안 | 민감정보 노출/우회 없음 | 토큰/개인정보 노출, 인증 우회 가능 |
| G4 | 치명 이슈 등급 | Critical 0개, 미해결 High 0개 | Critical 1개 이상 또는 미해결 High 1개 이상 |
| G5 | 검증 근거 | 모든 핵심 이슈에 `file:line` 근거 있음 | 추측성 코멘트, 근거 누락 |

## 품질 점수 (0~100)

점수는 `PASS` 보조 지표로 사용한다. 병합 차단은 필수 게이트가 담당한다.

| 영역 | 배점 | 기준 |
| --- | --- | --- |
| 비즈니스/도메인 정확성 | 30 | 플로우/요구사항 일치 여부 |
| API/타입/오류 처리 | 25 | 타입 안정성, 실패 분기 완결성 |
| 보안/인증 안전성 | 20 | 민감정보/권한/쿠키 처리 안정성 |
| 성능/렌더링 효율 | 15 | 불필요 렌더, 번들/패칭 비효율 |
| 접근성/UX 일관성 | 10 | 인터랙션/시맨틱/접근성 기본 준수 |

## 점수 등급

- `90~100`: 매우 안정 (PASS 권장)
- `75~89`: 안정 (PASS 가능, 개선 권고 포함)
- `60~74`: 조건부 (게이트 통과여도 개선 우선)
- `0~59`: 불안정 (HOLD 권장)

## 출력 형식 (강제)

아래 형식을 모든 검증 결과에 적용한다.

1. `Verdict: MERGE: PASS | MERGE: HOLD`
2. `Failed Gates: Gx, Gy` (없으면 `none`)
3. `Score: NN/100`
4. `Findings` (Severity 순 + `file:line` 근거)
5. `Next Action` (수정 우선순위 1~3개)

## 예외 규칙

- 긴급 핫픽스라도 `G3(보안)`와 `G4(치명 이슈)`는 우회 불가다.
- Medium/Low만 남은 경우에만 조건부 `PASS`가 가능하다.
