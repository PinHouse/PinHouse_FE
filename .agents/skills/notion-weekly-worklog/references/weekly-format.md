# 주간 작업 정리 페이지 형식

## 제목 형식

`M/D(월) ~ M/D(일) Wn 작업 정리`

예시:

- `5/11(월) ~ 5/17(일) W6 작업 정리`
- `5/18(월) ~ 5/24(일) W7 작업 정리`

## 본문 구조

```md
> 주간 일정 템플릿 기반으로 작성한 이번 주 작업 정리입니다.

---

## 🎯 이번 주 목표

> **스프린트:** Wn — 핵심 주제

- [x] 핵심 목표 1
- [x] 핵심 목표 2
- [x] 핵심 목표 3

---

## 📅 일별 체크리스트

### 월 (MM/DD)

- [x] 작업 내용

### 화 (MM/DD)

- [x] 작업 내용

### 수 (MM/DD)

- [x] 작업 내용

### 목 (MM/DD)

- [x] 작업 내용

### 금 (MM/DD)

- [x] 작업 내용

### 토 (MM/DD)

- [x] 작업 내용

### 일 (MM/DD)

- [x] 작업 내용

---

## ⚠️ 이슈 / 블로킹

| 이슈 | 담당 | 상태 |
| --- | --- | --- |
| 이슈 내용 | FE/BE/공통 | 추적 필요 |

---

## ✅ 주말 회고

**잘한 점**

- 항목

**개선할 점**

- 항목

**다음 주 예고**

- 항목
```

## 작성 규칙

- 요일별 작업은 완료 체크리스트 `- [x]`로 작성한다.
- 아직 완료되지 않은 작업은 `- [ ]`로 작성한다.
- 같은 작업이 여러 줄로 흩어져 있으면 하나의 의미 단위로 묶는다.
- 구조적 문제, lint 충돌, 책임 분리 필요 사항은 이슈 테이블에도 추가한다.
- 주말 회고는 한 주 전체를 요약할 수 있을 때만 작성한다.
