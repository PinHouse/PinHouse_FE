# Notion 주간 작업 기록 스킬

사용자가 오늘 작업 내용, 특정 요일 작업 내용, 또는 주간 작업 정리를 Notion에 추가해달라고 요청하면 이 스킬을 사용한다.

## 대상 위치

- Notion 허브: `사주 프로젝트 — 개발 관리 허브`
- 기준 페이지 형식: `5/4(월) ~ 5/8(금) W5 작업 정리`
- 스프린트 트래커 DB: `스프린트 트래커 (W1~W10)`
- 페이지 본문 템플릿: `references/weekly-format.md`

## 주차 규칙

- W5: 2026-05-04 ~ 2026-05-10
- W6: 2026-05-11 ~ 2026-05-17
- W7: 2026-05-18 ~ 2026-05-24
- 이후 매주 월요일부터 일요일까지 1씩 증가한다.
- 한 주가 지나면 새 W 페이지를 만들고, 기존 W 페이지에는 이전 주 내용만 유지한다.

## 날짜 매칭 규칙

- Asia/Seoul 기준 현재 날짜를 사용한다.
- 월요일부터 일요일까지 각각 `월`, `화`, `수`, `목`, `금`, `토`, `일` 섹션에 기록한다.
- 사용자가 "오늘 작업"이라고 말하면 현재 날짜의 요일 섹션에 추가한다.
- 사용자가 특정 날짜나 요일을 말하면 해당 섹션에 추가한다.
- 사용자가 날짜 없이 여러 날 작업을 제공하면 월요일부터 일요일 순서로 매칭한다.

## 페이지 생성 규칙

- 해당 주차 페이지가 있으면 기존 페이지의 해당 요일 섹션에 추가한다.
- 해당 주차 페이지가 없으면 허브 하위에 새 페이지를 만든다.
- 페이지 제목 형식은 `M/D(월) ~ M/D(일) Wn 작업 정리`를 사용한다.
- 새 페이지는 `references/weekly-format.md`의 구조를 따른다.

## 업데이트 규칙

- 기존 체크리스트 항목은 유지한다.
- 새 작업은 해당 요일 아래에 `- [x]` 체크리스트로 추가한다.
- 중복 항목은 만들지 않는다.
- 내용이 너무 길면 의미 단위로 묶어 3~7개 항목으로 정리한다.
- 문제, 리스크, 구조적 개선 필요 사항은 `⚠️ 이슈 / 블로킹` 테이블에도 반영한다.
- 주간 전체 내용이 충분하면 `✅ 주말 회고`의 잘한 점, 개선할 점, 다음 주 예고도 함께 정리한다.

## Notion 작업 절차

1. `사주 프로젝트 — 개발 관리 허브`를 검색하거나 기존 page ID를 사용한다.
2. 대상 W 페이지가 있는지 검색한다.
3. 있으면 fetch 후 기존 섹션을 보존하면서 해당 요일만 갱신한다.
4. 없으면 새 W 페이지를 생성한다.
5. 생성/수정 후 사용자에게 Notion 페이지 링크와 반영 요약을 알려준다.

## 주의사항

- 사용자가 명시하지 않은 작업 내용을 임의로 만들어내지 않는다.
- GitHub issue, PR, git log를 근거로 쓸 때는 근거를 확인한 뒤 요약한다.
- 사용자가 "푸쉬", "커밋" 등을 말하지 않는 한 로컬 파일 변경과 Git 작업은 하지 않는다.
