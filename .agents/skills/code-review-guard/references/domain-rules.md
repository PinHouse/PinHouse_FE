# Domain Rules (Saju Frontend)

## 핵심 사용자 플로우

1. `/saju` 입력 완료 후 결과 조회는 `/saju/result`로 이어져야 한다.
2. 인증 사용자 전용 마이페이지 기능은 비인증 시 로그인 유도 흐름을 따른다.
3. 결과/운세/궁합 데이터는 사용자 컨텍스트가 바뀌면 캐시가 분리되어야 한다.

## 데이터 처리 원칙

- 생성 API 클라이언트(`src/generated/api`)는 직접 수정하지 않는다.
- 서버 응답 스키마 변경 대응은 호출부 어댑터/가드에서 처리한다.
- 화면 표시값 포맷팅은 UI 레이어, 도메인 판정은 비즈니스 레이어에서 처리한다.

## 금지 사항

- 매직 스트링 기반 권한 판정
- 서버 응답을 신뢰한 무검증 렌더링
- 예외를 삼키는 빈 catch
