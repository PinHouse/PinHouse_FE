# 프롬프트 트리거 검증 스킬

스킬 `description`의 트리거 정확도를 점검할 때 사용한다.

## 사용 시점

- 사용자가 "프롬프트 테스트 하자", "트리거 검증해줘"라고 요청할 때
- 특정 스킬의 오탐/미탐이 의심될 때
- 스킬 description 수정 전/후 성능 비교가 필요할 때

## 읽기 규칙

- 기본으로 `references/description-eval-queries.md`를 읽는다.
- 여러 스킬을 동시에 점검할 때만 대상 스킬 `SKILL.md`를 추가로 읽는다.

## 운영 절차

1. 평가 대상 스킬을 지정한다.
2. `should_trigger`/`should_not_trigger` 세트로 분류 정확도를 점검한다.
3. 오탐/미탐 사례를 기록한다.
4. 필요 시 대상 스킬의 `description` 문장을 조정한다.
5. 같은 세트로 재검증해 개선 여부를 확인한다.

## 출력 형식

- `대상 스킬`
- `테스트 샘플 수`
- `오탐(FP) / 미탐(FN) / 정탐(TP) / 정거부(TN)`
- `수정 전/후 비교`
- `권장 description 수정안`

## 주의사항

- 평소 구현 작업 중에는 상시 실행하지 않는다.
- 테스트 시점에만 최근 프롬프트 8~20개를 대표 샘플로 사용한다.
- 점검 결과는 실제 사례 기반으로 기록한다.
