# Prompt Writing Examples (User Raw Samples)

> 운영 지침: 이 파일은 상시 작업용 reference가 아니다.  
> Agent는 기본 작업 흐름에서 이 파일을 읽지 않는다.  
> 사용자가 "프롬프트 예시 파일 보여줘/업데이트해줘"처럼 명시 요청한 경우에만 확인한다.

## 좋은 예시 (원문 그대로)

- `혹 오늘 커밋한 내용 확인할수 있을까?`
- `426d6aa2bffffd18b94003ebfec9f475502471a7 이거도 찾아보고 노션에 정리해줘 화요일로`
- `그러면 일단 디자인 시스템 부터 먼저 시작을 해보자 플랜을 세워봐`
- `응 작업하지말고 추천안을 줘봐`
- `그래 그러면 만들어줘봐`
- `git fetch 하면  refactor/#227 이 보일꺼야 거기로 checkout 하고 develop에서 변경된 내용을 가져가 그리고 commit 까지 해줄수 있어? 커밋하고 노션에도 올려주고 머지는 내가 할게`
- `그리고 푸쉬까지해줘`
- `지금 브렌치가 refactor 에 있짢아 그거 commit 하고 develop 으로 checkout 해서 merge 해줘`
- `그리고 develop에서 원격브렌치 내용을 pull 해줘`
- `그럼 프롬프트 테스트하자`

## 맥락 보강 예시

- 원문: `안녕`  
  개선: `안녕, 지금 /Users/chan/Documents/develop/saju 기준으로 오늘 커밋 요약부터 확인해줘.`

- 원문: `응`  
  개선: `응, 방금 제안한 3개 템플릿(ui-inventory/design-tokens/component-priority) 전부 생성해줘.`

- 원문: `음? 지금 브렌치 develop아냐?`  
  개선: `현재 브랜치가 develop인지 확인하고, 아니면 현재 브랜치명도 같이 알려줘.`

- 원문: `음??? 아닌디 .agents가 안보이니?`  
  개선: `saju 루트가 아니라 Frontend/.agents 경로까지 포함해서 다시 찾아봐. 결과는 절대경로로 알려줘.`

- 원문: `어디에다가 만드는건데??`  
  개선: `파일 생성 위치를 절대경로로 정확히 적어줘. SKILL.md랑 references 폴더 둘 다.`

- 원문: `원하면 다음으로 이 스킬을 실제로 쓰기 쉽게 references 템플릿(인벤토리 표, 토큰 표, 우선순위 표)도 같이 만들어드릴게요. 이거 말이야 이거 어디에다가 만드는거냐구`  
  개선: `그 references 템플릿 3개를 어느 디렉터리에 만들지 절대경로 + 파일명 목록으로만 답해줘.`

## 짧은 체크 규칙

1. 대상(브랜치/폴더/페이지)을 붙인다.
2. 행동(확인/생성/수정/커밋/푸시)을 명시한다.
3. 출력형식(절대경로/요약/표)을 지정한다.
